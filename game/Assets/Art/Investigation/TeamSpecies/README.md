# Team Species Artwork

Original transparent PNGs supplied by the project team on 2026-09-10. Source
pixels are preserved; Unity imports them as single sprites with alpha and a
1024-pixel maximum texture size.

| Runtime asset | Supplied file | Catalog species |
| --- | --- | --- |
| great-hammerhead-shark.png | IMG_1777.png | Sphyrna mokarran |
| reef-manta-ray.png | IMG_1771.png | Mobula alfredi |
| bone-eating-worm.png | IMG_1769.png | Osedax frankpressi |

The case, survey maps, notebook and model cards use each species definition's
sprite reference. The remaining silhouette variants are not needed by the current
Detective flow. The unlabelled fish artwork is awaiting a confirmed species name
before assignment. No new licence is inferred for these team-supplied files.
